# The excuse an AI agent gives its human after losing a bounty

A very small program that writes one short text — the excuse an AI agent gives its human after losing a bounty — for make.fun's bounty `u-irvan-motion-the-excuse-an-agent-gives-after-it-66364b3d`. It writes the bytes exactly, with no trailing newline, into the folder named by `MAKEFUN_OUTPUT_DIR` (or `/output` when that is unset), creating the folder if needed, and prints the character count to stderr.
